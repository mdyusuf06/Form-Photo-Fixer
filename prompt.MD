Build a client-side web application called "Form Photo Fixer" using Next.js, React, and Tailwind CSS. The tool gets a photo and signature ready for exam and job application forms in one step.   All image processing must happen locally in the browser so that large phone photos can be processed even if the user goes offline (no backend image processing).   Core Requirements & UI:Uploads: Allow users to upload both a photo and a signature.   Form Presets Dropdown: Create a dropdown menu containing at least 3 real-world exam presets (e.g., UPSC, SSC, IBPS). Each preset must enforce specific physical dimensions (like 3.5 x 4.5 cm converted to pixels) and a strict maximum file size (in KB).   Custom Preset: Include an option for users to manually input their own required dimensions and KB limit.   Cropping with Face Guide: Integrate a client-side image cropping library (such as react-image-crop). Include a visual 'face guide' overlay on the crop box to help users properly align their head and shoulders.   Dynamic Compression: Write a specific utility function using the browser's Canvas API (toBlob or toDataURL). This function should take the cropped image and iteratively lower the JPEG/WEBP image quality step-by-step until the output file is just under the required KB limit.   Real-time Feedback UI: Display a progress bar reflecting the current file size vs. the limit (e.g., "39 KB of 50 KB limit"). Show a green "✓ Ready to upload" text when the file meets the criteria.   Export: Provide a "Download photo" (and signature) button that saves the finished, compliant files to the user's computer.   Implementation Order:
Start by scaffolding the UI layout, upload state, cropping tool, and download buttons. Once that base is functional, write and integrate the step-by-step Canvas compression algorithm to enforce the file size limits. Ensure the computer's downloaded file details perfectly match the target KB limits.
